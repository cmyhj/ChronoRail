## 数据约定

本地 `Version` 和远程 `GameVersion` 均新增可选 `livestream` 对象，其三个字段也都可选：

| 字段 | 含义 |
| --- | --- |
| `startAt` | 官方确认的直播开始时间，显式包含时区的 ISO 字符串 |
| `endAt` | 官方确认的直播结束时间，不可按常见直播时长推算 |
| `officialUrl` | 已核验的官方直播或公告入口，绝对 HTTP(S) URL |

旧数据无需迁移。JSON 存储、导入导出沿用现有对象保留逻辑；远程历史读取、时间轴映射、本地与远程合并和版本同步均传递新增字段。远程没有字段时，版本同步保留本地直播信息；同一版本在时间轴优先使用本地直播对象，缺失时回退到远程。显式空对象可表示待公布。不增加数据采集器或猜测官方公告；现有 CI 更新脚本未改动，未来维护正式公告数据时须注意它会重新生成米哈游版本记录。

时间格式支持 `YYYY-MM-DDTHH:mm[:ss[.SSS]]Z` 或显式 `±HH:mm` 偏移（最大 ±14:00）。拒绝不含时区、未知偏移 `-00:00`、越界小时/分秒、日期滚动和无效闰日。显示统一为北京时间，并明确标注 `UTC+08:00`，不依赖浏览器所在时区。

仅当开始、结束时间都有效，且结束晚于开始、当前时间达到结束时，才显示“直播已结束”。没有可信结束时间时显示“直播已开始（结束时间未确认）”，不会把开始等同于正在直播。无效数据显示待核实；缺失时间与入口显示待公布。链接过滤拒绝其他协议、相对地址、用户密码、空白、控制字符和反斜杠；通过格式过滤不等于认证官方身份，录入者仍须核实来源。外链使用 `noopener noreferrer`。

## 界面

首页在现有版本概览与时间轴之间新增“版本前瞻直播”，版本详情也显示对应卡片，沿用深色面板、边框、靛蓝强调色和响应式网格。保留所有原有可见文本和 aria 标签。每个游戏至少展示最新已知版本的待公布卡片，同时保留其他带直播信息的版本；没有版本时显示“版本待公布”。

卡片展示游戏、版本、时间、倒计时或已开始/已结束状态以及有效官方链接。每个已挂载预告区每秒读取当前绝对时间，避免累加计时漂移；卸载清除 interval。倒计时不设置每秒播报的 aria-live，避免读屏干扰。远程异步加载也增加了取消标记，避免组件卸载或游戏列表变更后写入旧结果。
